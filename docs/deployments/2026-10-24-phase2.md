# Phase 2 integration deployment

This integrates CLI PR #16 with `main` at `0fded18` and finishes the shared data
store migration. The latest main dashboard, Windows workspaces, account settings,
SSH access, quotas and workflows are retained.

Preflight found that the teammate had already deployed `0fded18` to both control
and host, and provisioned RDS, KMS and the token rotation Lambda. CDK diff reports
no changes. No CDK deployment is required for this integration.

Before changing the application, the RDS application role signed in with IAM over
TLS. A consistent data snapshot was saved with mode 0600 on the control box.
The legacy SQLite integrity check passed; it contains two tasks and one CLI
credential to import. Both existing Linux VMs were stopped and had no errors.

Local verification: 204 tests passed, one Linux-only PTY test skipped on macOS;
87 control/CLI tests passed against real local Postgres 16. Typecheck and the web
production build passed. CDK diff found zero changes. Additional live acceptance
results will be recorded below after deployment.

GitHub OAuth is not configured in the deployed environment. Token-based GitHub
connections remain supported; a real OAuth consent/callback test requires the
owner to configure an OAuth app and approve it in their browser.
